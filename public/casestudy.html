01

Title & Overview

AnetAIS is a 0→1 AI creative studio product — a web application that unifies text-based chat, AI image generation, AI video generation, and a Canva/Figma-inspired design editor into one coherent platform. The product targets creators, marketers, and AI enthusiasts who currently juggle four or five separate tools to produce visual AI content.

🎨

Image Studio

Masonry explore gallery + prompt-based image generation with style presets, aspect ratio control, and masonry My Creations grid.

🎬

Video Studio

Multi-model video generation with camera motion presets, style presets, duration/FPS/aspect ratio controls, and a history library.

✏️

Design Studio

Full canvas editor inspired by Canva + Figma: layers panel, drag-and-drop elements, prompt-driven generation, and inline image/video output.

02

Problem Statement

Creators who want to produce AI-generated visual content are forced to use multiple disconnected tools — Midjourney for images, Runway or Kling for video, Canva for design, ChatGPT for copy — with no unified history, no shared creative context, and no single output destination.

  • Context switching cost: Moving between 4–5 tools breaks creative flow and multiplies re-prompting effort.
  • No creative continuity: A generated image can't be directly edited, composited, or sent to video within the same environment.
  • Scattered history: Outputs are spread across platforms — no single gallery or generation log.
  • Steep learning curve: Each tool has its own UI paradigm, billing, and API keys — overwhelming for non-technical creators.
  • No collaborative editing: Teams can't share a canvas or creative session across tools.

Research

Research was conducted across four methods to understand the creator workflow and identify gaps in existing tools.

Methods Used

  • 🗣️User interviews (8): 30-min sessions with freelance designers, content creators, and marketers who use ≥2 AI tools regularly.
  • 📊Survey (47 responses): Quantified pain points, tool usage frequency, and willingness to pay for a unified solution.
  • 🔍Competitive analysis: Evaluated Midjourney, Runway, Pika, Canva AI, and Adobe Firefly across 12 UX dimensions.
  • 📱Heuristic evaluation: Applied Nielsen's 10 heuristics to the top 5 competing tools to identify systemic UX gaps.

Key Findings

  • "I generate an image in Midjourney, download it, upload to Canva, add text, export, then import into Runway. It's insane." — Interviewee #3
  • 81% of survey respondents wanted image-to-video handoff without re-uploading.
  • Creators rated "inspiration browsing" as highly important (4.3/5) — validates the Explore page.
  • All five competitors lacked a canvas editor as part of their generation flow.

Design Principles

🧭
Flow over features
Every feature exists to advance a creative flow. The Design Studio is not in the nav — it's a destination you arrive at through intent, not discovery.
⚡
Parameters, not prompt walls
Style presets, camera motion grids, and visual ratio pickers replace intimidating blank prompt boxes with structured, clickable decisions.
🌑
Dark-first, theme-aware
CSS variable tokens (--bg-base, --text-primary) power both dark and light themes. Gradients and colored borders replace flat grays for depth.

Explore / Home — Masonry Gallery
High-impact screen

The explore page is the first impression. I used CSS columns masonry layout (not CSS Grid) so images flow at their natural aspect ratios — creating a rich, Pinterest-style discovery experience without JavaScript masonry libraries.

  • → Always-visible stats overlay (views + likes) on each card
  • → Hover reveals: like, download, share, prompt preview, "Try this" CTA
  • → 9 content filter tabs with per-tab unique item sets
  • → Search filters within active tab
Detail Modal Anatomy
  • 📸 Left 54% — full-height image + nav arrows + counter
  • 👤 User row — avatar, handle, followers, Follow btn, ❤ likes
  • 📝 Derived title from prompt first segment
  • 🏷 Meta badges — date · tool · AI Generated · view count
  • 🏷 Keyword tags extracted from prompt
  • ⚙️ Generation Parameters (collapsible) — prompt copy, 4 model cards, base info
  • 💬 Comments — input + 3 mock entries with like/reply
  • 🎬 Sticky CTAs — Generate Video + Try in Design Studio
Design Studio — Canvas Editor
Flagship feature

Full-screen canvas editor accessible only through explicit user intent (via "Try in Design Studio" CTA). Key design decisions:

  • → Left sidebar: 6 tabs (Layers, Templates, Elements, Text, Photos, BG)
  • → Layers panel: drag-reorder, inline rename, right-click context menu
  • → Bottom bar: Layers toggle, Page 1/1, zoom controls
  • → Floating prompt bar: Image/Video mode tabs + generate button
  • → Generation overlay inside canvas with animated rings + stage labels
  • → Right panel: Document properties (canvas size, background color)
  • → Element properties panel contextual to selection
  • → Dual mode: Image gen + Video gen with different prompt suggestions
  • → History undo/redo stack for canvas actions
  • → Template gallery with 6 social/marketing presets
Video Studio — Advanced Generation Controls
Advanced UX

Most video generation tools expose raw sliders. AnetAIS replaces these with opinionated preset grids that communicate visually what each option does:

5 Model Options

Each with name, badge (Latest/Popular/Fast), and sub-description — helps non-technical users choose confidently.

10 Camera Motions

Visual icon grid (Static, Pan L/R, Tilt U/D, Zoom In/Out, Orbit, Dolly, Handheld) with tooltip descriptions. Motion strength slider appears only when a motion is selected.

Credits + Time Estimate

Dynamic cost and time preview before generating — sets expectations and reduces frustration when results take time.

Testing & Iteration

Usability Testing Findings

Design Studio was hidden — users couldn't find it

"I kept looking for a 'Design' button in the sidebar." — Tester #2

Layers panel as floating overlay was disorienting

"It covered my canvas and I didn't know where to click." — Tester #5

ProfileMenu clipped off-screen on smaller viewports

The popup used absolute positioning relative to sidebar, not viewport.

Detail modal felt shallow — users wanted more generation context

"I want to see what model and settings made this." — Tester #4

My Creations click opened an in-page editor, not Design Studio

Users expected the full canvas editor, not a minimal overlay.

Iterations Made

→

Design Studio removed from sidebar nav

Access gated to "Try in Design Studio" CTA in detail modal and My Creations click — enforces intentional flow, reduces confusion.

→

Layers panel moved to sidebar section

Layers button in bottom bar toggles the left sidebar panel between Templates and Layers — no floating overlay, no canvas obstruction.

→

ProfileMenu changed to fixed positioning

Changed from absolute to fixed left-[72px] bottom-4 — always visible, never clipped.

→

Detail modal completely redesigned (Liblib-inspired)

Added: model cards with tier badges, collapsible generation params, comment section, sticky Generate Video + Design Studio CTAs.

→

My Creations → Design Studio navigation

Click on any creation card in My Creations tab now navigates directly to Design Studio with prompt pre-filled.

Reflection & Learnings

What I'd Do Differently

  • 1.Start user testing earlier — the Design Studio discoverability issue was only found in round 2. A quick prototype test in week 1 would have caught it.
  • 2.Define the design token system upfront. CSS variable naming (--bg-base, --bg-muted, --bg-hover, --bg-active) was stable but evolved inconsistently in early components.
  • 3.Invest earlier in mobile-responsive layout for the Design Studio — the canvas editor currently works best at 1200px+ and needs a mobile-adapted view.

Key Learnings

  • ✓Navigation is a product decision, not just a UX pattern. Removing Design Studio from the sidebar wasn't hiding a feature — it was defining the product's creative philosophy.
  • ✓Preset grids beat sliders for non-technical users. Camera motion presets, style presets, and visual ratio pickers removed friction without reducing capability.
  • ✓Detail modals are underrated conversion surfaces. The Liblib-inspired redesign turned a simple image preview into a rich, explore-and-convert moment with dual CTAs.
  • ✓Fixed positioning beats absolute for floating UI. ProfileMenu, generation overlays, and floating prompt bars need viewport-relative positioning to work reliably across screen sizes.
